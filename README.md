# RFID Smart Trolley System

## 📌 Description

This project uses RFID technology to automatically detect items and calculate total bill.

## 🧰 Components Used

* Arduino Nano
* RFID RC522
* 20x4 LCD
* LEDs
* Buzzer
* Push Button

## ⚙️ Features

* Item detection using RFID
* Multiple item count
* Add/Remove functionality
* Total price calculation

## 💻 Technologies

* Arduino IDE
* Embedded C

## 🚀 Future Scope

* Mobile app integration
* WiFi billing using NodeMCU
